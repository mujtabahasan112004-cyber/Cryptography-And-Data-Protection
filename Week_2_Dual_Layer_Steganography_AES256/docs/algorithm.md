# Cryptographic & Steganographic Algorithms: Dual-Layer Medical Stego

## 1. Mathematical Algorithms

### 1.1 Key Derivation Function (PBKDF2-HMAC-SHA256)
Given passphrase $P$, salt $S$ ($|S| = 16$ bytes), iteration count $c = 600,000$, and output key length $dklen = 32$ bytes:
$$DK = \text{PBKDF2}(P, S, c, dklen) = T_1$$
Where:
$$T_1 = F(P, S, c, 1) = U_1 \oplus U_2 \oplus \dots \oplus U_c$$
$$U_1 = \text{HMAC-SHA256}(P, S \parallel \text{INT\_32\_BE}(1))$$
$$U_j = \text{HMAC-SHA256}(P, U_{j-1})$$
This computational work factor imposes a massive barrier against offline dictionary and rainbow-table attacks.

### 1.2 Authenticated Encryption (AES-256-GCM)
Galois/Counter Mode consists of two mathematical operations:
1. **CTR Mode Encryption**: Plaintext $P$ is XORed with successive blocks of encrypted counter values generated by AES-256 under key $K$:
   $$Y_i = \text{AES-256}_K(IV \parallel \text{Counter}_i)$$
   $$C_i = P_i \oplus Y_i$$
2. **GHASH Authenticator**: A polynomial evaluation over the Galois field $\text{GF}(2^{128})$ parameterized by hash key $H = \text{AES-256}_K(0^{128})$:
   $$\text{GHASH}_H(X_1, \dots, X_m) = \sum_{i=1}^m X_i \cdot H^{m-i+1} \pmod{x^{128} + x^7 + x^2 + x + 1}$$
   The resulting authentication tag $T$ verifies that neither the ciphertext $C$, nor the nonce $IV$, nor the associated data $AD$ have been tampered with.

## 2. Steganographic Algorithms

### 2.1 Layer 1: Fisher-Yates Pseudo-Random Permutation
Let total available channel bytes in the image be $N = \text{Width} \times \text{Height} \times \text{Channels}$.
1. Derive 64-bit seed from Stego-Key:
   $$\text{Seed} = \text{UInt64}(\text{SHA-256}(b"\text{PERM\_SALT\_}" \parallel \text{Key})[0..7])$$
2. Initialize array $A = [0, 1, 2, \dots, N-1]$.
3. For $i$ from $N-1$ down to 1:
   - Pick random integer $j \in [0, i]$ using PRNG(Seed).
   - Swap $A[i]$ with $A[j]$.
4. The resulting sequence $A$ gives the scattered spatial slot coordinates.

### 2.2 Layer 2: Least Significant Bit Modulation
Let $b_k \in \{0, 1\}$ be the $k$-th bit of the serialized stego envelope:
$$p'_k = (p_k \ \& \ \text{0xFE}) \ | \ b_k$$
Extraction:
$$b_k = p'_k \ \& \ \text{0x01}$$

## 3. Image Fidelity Evaluation

### 3.1 Mean Squared Error (MSE)
For an $M \times N$ image with $C$ color channels:
$$\text{MSE} = \frac{1}{M \cdot N \cdot C} \sum_{i=0}^{M-1} \sum_{j=0}^{N-1} \sum_{k=0}^{C-1} [I_1(i, j, k) - I_2(i, j, k)]^2$$

### 3.2 Peak Signal-to-Noise Ratio (PSNR)
$$\text{PSNR} = 10 \cdot \log_{10} \left( \frac{\text{MAX}_I^2}{\text{MSE}} \right)$$
For 8-bit image data ($\text{MAX}_I = 255$):
$$\text{PSNR} = 20 \cdot \log_{10}(255) - 10 \cdot \log_{10}(\text{MSE}) \approx 48.13 - 10 \cdot \log_{10}(\text{MSE})$$
When MSE is very low ($\approx 0.002$), $\text{PSNR} \approx 74.9\text{ dB}$, confirming that alterations are negligible.
